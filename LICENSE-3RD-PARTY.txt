3) FFmpeg / ffprobe — 音频工具链二进制(随安装包分发)
   来源:   https://ffmpeg.org/  (本项目打包的是 Windows 静态构建,取自 ffmpeg.org 的
           "Windows builds" 页面所链接的发布方)
   许可:   FFmpeg 本体为 LGPL v2.1+;若构建启用了 --enable-gpl(常见静态构建即是),
           则整体按 GPL v2+ 分发。本项目的构建取自含 GPL 组件的静态包,按 GPL v2+ 处理。
           许可全文: https://ffmpeg.org/legal.html
   用法:   仅作子进程调用(转码为 FLAC、探测时长/编码),不链接、不修改其源码。
   ⚠️ 合规要点:随包分发 FFmpeg 二进制时,必须同时提供
       (a) 许可全文与来源说明(本文件);
       (b) 获取对应源码的方式(见 https://ffmpeg.org/download.html );
       (c) 本项目对 FFmpeg 未做修改,故无需提供补丁。
   ffprobe: 同样是 FFmpeg 项目的一部分,但**当前不随包分发**(安装目录会多约 97MB,
           而缺它时代码用 `ffmpeg -i` 的 stderr 兜底探测,功能不受影响)。若将来随包发布,
           请在此处一并登记,见 tools/fetch-ffmpeg.mjs 顶部说明。

   SDK/二进制入库位置: build/ffmpeg/ffmpeg.exe(*.exe 已被 .gitignore 忽略,不进仓库)
   打包声明: package.json 的 build.extraResources → resources/ffmpeg/ffmpeg.exe

4) uiverse.io — 第三批采用(2026-09-23)
   许可:   MIT License
   归档:   同一 galaxy 仓库,本批稀疏拉取 Cards / Notifications / Toggle-switches / Patterns
   原则不变:取"动作与形态",颜色尺寸一律改写为项目主题 token。

   已采用:
   - 进度条流动微光(.sf-shimmer)
       作者: CheneyLin(文件名 CheneyLin_lazy-goat-96,Tags: animation, progress bar, loader)
       改写: 原组件用一张 base64 PNG 箭头贴图 + background-position 位移;这里换成**纯 CSS

     本项目 Toast 的"自动消失倒计时条"是自研实现(按 duration 参数驱动 scaleX 收缩),

5) uiverse.io — Checkboxes 分类采用(2026-09-23)
   许可:   MIT License
   归档:   同一 galaxy 仓库,分类目录 Checkboxes

   已采用(动作:框→对勾的形变 —— "把对勾写出来"):
   - sans-script_modern-stingray-0(Tags: checkbox, square)
   - G4b413l_smooth-duck-62(Tags: checkbox)
       改写: 两者都需要一个额外的 span 做形变载体(框的边框旋转收窄后长成对勾)。
             本项目不引入额外 DOM,改为在 input 的 ::after 上用**裁剪擦除**(clip-path
             从左上角展开)实现同一动作;颜色走 --sf-check-mark/token,尺寸沿用 16px 体系,
             并对 prefers-reduced-motion 关闭动效与回弹。
       用于: 列表/歌单/去重面板的多选框(src/components/MusicList.vue、HomeView、PlaylistView)
       实现: src/styles/controls.css 的 .sf-check

   顺带修掉一个**功能性缺口**(非本项目既有能力):全选框此前只绑 checked,
   部分勾选时与"一个都没选"看起来完全一样 —— 现在接上既有的 :indeterminate 样式
   (一横杠),三个状态可区分。
   另:本批之后又查看了 Radio-buttons(102)与 Forms(180)两个分类,均**未采用** ——
   Radio-buttons:本项目没有单选场景(模式切换是按钮组、排序是 chips、开合是 switch),
   硬套等于凭空造需求;Forms:读到的是注册/上传类表单(固定色 + 暗卡片),本项目的
   "表单"只有标签编辑弹窗,其输入框基座与聚焦环早在第 2 节就已从 Inputs 分类采用。
   下次要探索这两个分类前,先看这条。

   已采用:
   a) 开关轨道悬停渗出主色
       作者: omriluz(omriluz_tough-crab-66,Tags: switch)
       改写: 原组件靠 Tailwind 的 bg-[length:100%_500%] 让渐变尺寸在悬停时变化;
             这里改为从下往上渗出的 token 渐变(background-size 0→100%),
             不动 ON 态的实色,避免"悬停盖掉状态色"。
       用于: 设置页所有开关(src/styles/global.css 的 .switch)

       作者: Cornerstone-04(Cornerstone-04_chatty-eel-89,Tags: button)
       改写: 原组件是 ::after 实色反转(scaleX 0→1、transform-origin: left),会盖住文字;
             这里改成极淡的主色 alpha 层,压在背景之上、文字之下。
       用于: .btn--ghost 与 .chip(src/styles/controls.css)
   c) 卡片悬停自下而上渗出一层浅底 —— **已按用户要求移除(2026-09-23)**
       作者: Ali-Tahmazi99(Ali-Tahmazi99_curly-insect-62,Tags: card)
       曾实现: 原组件 ::before 的 height 0→100% 实色铺满整卡,当时改成 --bg-hover 浅渐变。
       移除原因: 用户看过后要求去掉(卡片本身已有悬停抬升 + 阴影,再叠一层渗出显得多余)。
       备注: 这条已不在代码里,不要再加回来;若将来要恢复,记得连 ::before 的
             position:relative 容器一起加。
   d) 输入框聚焦时占位符变淡
       作者: JaydipPrajapati1910(JaydipPrajapati1910_black-impala-70,Tags: input effect)
       改写: 只取 :focus::placeholder 的颜色过渡这一条(原组件的立体/透视效果未采用)。
       用于: 全部文本输入框(src/styles/global.css)

   说明:开关那条原本被判定为"现有 .switch 已够好、不必替换"(见第 4 节),本批是用户点名
   要看这个分类后重新挑选的 —— 换掉的是**新增的悬停反馈**,不是整体替换控件。
